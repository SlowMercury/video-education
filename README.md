# Руководство по созданию видео с ИИ

Первая HTML-версия учебного материала на основе заметок от 4 сентября 2026 года. Тёмное оформление, восемь уроков и отдельный экран с библиотекой примеров. Учебный текст отредактирован и дополнен практическими заданиями. Исходный Markdown с сообщениями сохранён отдельно.

## Файлы

- `index.html` — вся страница, оформление и встраивание постов X. Открывается как отдельный файл в браузере.
- `server.mjs` — небольшой сервер для Railway, без внешних зависимостей.
- `package.json` и `railway.json` — параметры запуска на Railway.
- `PLAN.md` — согласованный план разработки по этапам.
- `PROGRESS.md` — текущее состояние, результаты проверок и следующий шаг.

## Локальный запуск

Нужен Node.js 22 или новее. В папке проекта выполните:

```sh
npm start
```

Откройте `http://localhost:4173`. Установка npm-пакетов не требуется. Без сервера можно открыть `index.html` напрямую. Для постов из X требуется интернет.

## Добавление постов из X

Можно присылать ссылки помощнику вместе с коротким пояснением, что показывается в ролике. Он добавит пост в подборку и свяжет его с главой.

Для ручного изменения найдите в конце `index.html`:

```html
<script id="x-examples" type="application/json">
```

Между тегами хранится массив объектов со следующими полями:

| Поле | Содержание |
| --- | --- |
| `url` | Настоящая ссылка вида `https://x.com/имя/status/числовой_ID` |
| `lesson` | Идентификатор главы из списка ниже |
| `title` | Название примера |
| `author` | Имя автора и дата поста |
| `watchFor` | На какие детали видео смотреть |
| `practice` | Какое действие предложить ученику |

Идентификаторы глав: `idea`, `first-frame`, `character`, `prompt`, `motion`, `storyboard`, `generation`, `editing`.

Посты появляются на экране «Библиотека примеров» по адресу `/#examples`. Каждый разбор содержит ссылку на свою главу. Порядок в массиве определяет порядок на странице. Уже добавлены два разных поста Reid Hannaford, которые предоставил автор курса:

- [Сложная сцена из простых форм — 25 июня 2026](https://x.com/reidhannaford/status/2070145120658137385)
- [Постановка сцены засады — 29 июня 2026](https://x.com/reidhannaford/status/2071595581508563168)

Повтор первого поста исключён. Оба поста подтверждены через официальный oEmbed X. Комментарии основаны на предоставленном тексте постов; подробный разбор самих видео можно расширить отдельно.

Используется официальный виджет X. Пост сохраняет авторство и встроенные видео или фотографии. Виджеты загружаются по мере приближения к ним при прокрутке. Видео не скачиваются на сервер. Если пост удалён, закрыт или X недоступен, остаётся ссылка на оригинал. Перед публикацией проверяйте примеры в браузере.

В JSON используйте обычный текст. Последовательность `</script>` в текстовом поле нужно записывать как `<\/script>`, чтобы не закрыть HTML-тег раньше времени. Ссылка проверяется по домену и формату ID; произвольный HTML в поля вставлять не нужно.

## Размещение на Railway

1. Исходный код хранится в [SlowMercury/video-education](https://github.com/SlowMercury/video-education), основная ветка — `main`.
2. Проект Railway называется `video-creation`; веб-сервис подключается к этому репозиторию.
3. Запуск задан в `railway.json`: `npm start`. Отдельной сборки нет.
4. После успешного запуска создайте публичный домен в настройках сервиса.

Сервер слушает `0.0.0.0` и порт из переменной `PORT`, которую задаёт Railway. Проверка готовности доступна по `/healthz`. Из интернета сервер отдаёт только учебную страницу и проверку готовности.

Первая версия предназначена для открытого доступа по ссылке.

Публикация выполняется в рамках первого этапа. Ссылка на сайт и состояние развёртывания фиксируются в `PROGRESS.md`. Комментарии и вопросы появятся на следующих этапах.
