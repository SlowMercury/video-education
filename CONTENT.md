# Как добавлять уроки и примеры

Учебные материалы находятся в `index.html`; обсуждения хранятся отдельно в PostgreSQL. Изменение текста или порядка примеров не должно менять идентификаторы обсуждений.

## Что прислать для нового видео

Достаточно ссылки на пост X и одного предложения: чему этот пример должен научить. Если есть исходники, добавьте первый кадр, точный промпт, модель и режим, видеореференс или файл Blender. Укажите, какие материалы можно публиковать.

Для каждого примера полезны три пояснения: какой результат мы видим, на что обратить внимание и какое небольшое упражнение повторить. Если точных настроек нет, пишем только подтверждённое. Собственный учебный промпт помечаем отдельно; не выдаём его за промпт автора поста.

## Добавить пост X

1. В `index.html` найдите `<script id="x-examples" type="application/json">`.
2. Добавьте объект в массив. Все текстовые поля обязательны для проверки содержания:

```json
{
  "url": "https://x.com/USERNAME/status/POST_ID",
  "lesson": "motion",
  "title": "Что показывает этот пример",
  "author": "Имя автора · дата исходного поста",
  "watchFor": "Подтверждённое описание приёма и вопрос для наблюдения.",
  "practice": "Одно небольшое действие, которое ученик может повторить."
}
```

Замените `USERNAME` и `POST_ID` настоящими значениями. Не вставляйте HTML из кода встраивания X: сайт показывает только видео в обычном плеере с подписью автора и ссылкой на источник. Для текста с `</script>` используйте `<\/script>` в JSON. Третий вариант того же поста с параметрами ссылки не является новым примером — числовой ID должен быть уникальным.

3. Добавьте объект `video` с полями `src` (прямая MP4-ссылка на `https://video.twimg.com/...`), `poster` (обложка на `https://pbs.twimg.com/...`), `width` и `height` (пропорции кадра, например 2 и 3). Эти значения берутся из метаданных исходного публичного поста, а не конструируются из его ID. Можно получить JSON по адресу `https://cdn.syndication.twimg.com/tweet-result?id=POST_ID&lang=en&token=0`: MP4 находится в `mediaDetails[].video_info.variants`, обложка — в `media_url_https`, пропорции — в `video_info.aspect_ratio`. Выбирайте MP4 до 1080p, если доступен. Если X перестал предоставлять метаданные, пришлите разрешённый источник видео. Файлы не копируются на сервер; если ссылка перестала работать, обновите её по исходному посту. Текст поста и социальные кнопки не встраиваются.
4. Укажите главу: `idea`, `first-frame`, `character`, `prompt`, `motion`, `storyboard`, `generation` или `editing`.
5. Запустите `npm run check:content`. Проверка найдёт дубликаты постов, неправильные ссылки, отсутствующие поля и ссылки на неизвестные главы.
6. Откройте локальную библиотеку и проверьте название, подпись, источник, связь с главой и форму обсуждения. Нажмите воспроизведение и убедитесь, что время идёт; одной проверки HEAD недостаточно. Если X недоступен, должна оставаться ссылка на оригинал.
7. Опубликуйте изменения в `main`. После развёртывания проверьте нужный пример на сайте. При старте сервер добавит его в каталог обсуждений.

Постоянная ссылка на пример: `/#example-POST_ID`. Например: [первый разбор](https://video-education-production.up.railway.app/#example-2070145120658137385). Две первоначальные ссылки `#example-1` и `#example-2` сохранены для совместимости.

Чтобы показать тот же пример внутри урока, добавьте в его текст `<figure class="lesson-demo" data-example-preview="POST_ID">` с подписью и ссылкой на исходный пост. Сам пост уже должен быть в JSON-каталоге. Такой показ не создаёт ещё одно обсуждение примера: под уроком остаётся обсуждение урока, в библиотеке — обсуждение видео.

## Что сохраняет обсуждения

- Для урока ключ — `lesson:ID_СЕКЦИИ`. Можно менять заголовок и содержание; не меняйте `id` существующего урока.
- Для примера ключ — `x:POST_ID`. Можно менять порядок, пояснения и связанную главу; комментарии останутся у того же поста.
- Другой пост X получает новое обсуждение. Не заменяйте ID, чтобы перенести старые комментарии на другое видео.
- Удалённый из каталога пример становится неактивным; его комментарии не стираются. Возврат того же ID восстанавливает доступ к обсуждению.

При добавлении нового урока сохраните структуру начала секции, которую читает каталог: `<section class="lesson" id="..."><div class="lesson-top"><span class="chapter-number">...`. Также добавьте урок в основное и мобильное содержание и в `chapterNames`. После этого проверьте `npm run check:content`; измените ожидаемое количество уроков в интеграционной проверке только для намеренного изменения состава курса.

## Формат подробного урока

Урок 05 — первая версия образца: результат в исходном видео → задача → исходные материалы → шаги → явно помеченные учебные промпты → сравнение → типичные ошибки → самостоятельная работа. Промпты упражнения с шаром пока не проверены в видеогенераторе; не описывайте их как гарантированный рецепт или как точные настройки Reid Hannaford.

Когда появятся собственные результаты, добавьте первый кадр, фактический промпт и настройки, удачную и неудачную версии и объяснение конкретной правки. Это сделает разбор воспроизводимым.

Для встроенных видео сохраняйте `Referrer-Policy: same-origin` в ответах сервера и `<meta name="referrer" content="same-origin">` в HTML. Это не передаёт адрес страницы внешним медиасерверам; при проверке 4 сентября 2026 X отвечал 403 на MP4-запросы с Referer нашего сайта, а без него — 206 с видеоданными. Проверка Origin для комментариев остаётся отдельной.
